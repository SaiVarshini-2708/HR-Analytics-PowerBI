# HR Analytics Dashboard

## Overview
An interactive HR analytics dashboard developed using Microsoft Power BI to explore employee attrition and workforce metrics.

## Key Metrics
- Total employee count
- Employee attrition and attrition rate
- Average employee age
- Average salary
- Average years at the company

## Visualizations
- Attrition by gender
- Attrition by education
- Attrition by age group
- Attrition by salary slab
- Attrition by job role
- Job satisfaction matrix

## Tools Used
- Microsoft Power BI
- DAX
- Data visualization and analysis
